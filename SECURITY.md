# Security reports

Report a suspected vulnerability through GitHub's private vulnerability reporting
for this repository, under Security, then Report a vulnerability.

Include the affected version, reproduction steps using synthetic data and the
expected impact. Do not post credentials, personal filenames or private screenshots
in a public issue. If private reporting is unavailable, open an issue asking for a
private reporting channel without including the vulnerability details.

The Private folder feature hides filenames in the menu. It is not access control
or encryption. No independent security audit is claimed.
